# SplitSmart

A simple and interactive web application designed to help friends split bills and manage shared expenses fairly.

## About the Project

SplitSmart is a web-based bill-splitting application that simplifies the process of calculating individual payments when sharing expenses with others.

Users can organise shared food items, assign expenses and calculate how much each person needs to pay. The application also supports additional charges and provides convenient ways to share the bill summary.

## Features

- **Participant Management** – Add participants involved in a shared bill.
- **Food Item Management** – Add food items and assign them to participants.
- **Bill Calculation** – Calculate individual payments based on selected items.
- **Additional Charges** – Distribute extra charges proportionally among participants.
- **WhatsApp Sharing** – Share the bill summary through WhatsApp.
- **Print Support** – Print or save the bill summary as a PDF.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Purpose

This project was developed to practise front-end web development, JavaScript functionality, data management and interactive user interface design.

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using SplitSmart.
